Independent Research

Cluster Radioactivity of Superheavy Nuclei — ASAF Model

A computational study implementing the Analytical Superasymmetric Fission (ASAF) model to predict half-lives of cluster radioactivity from superheavy nuclei (Z = 108–118), for emitted clusters ranging from 14C to 86Kr. The work corrects three failures in a prior alpha-decay-specific implementation by using the Liquid Drop Model deformation energy, a linear shell correction, and full numerical WKB barrier integration — reproducing published ASAF half-lives with an RMS deviation of 1.49 in log10 T1/2.

Keywords: cluster radioactivity, superheavy nuclei, WKB approximation, quantum tunnelling, liquid drop model
